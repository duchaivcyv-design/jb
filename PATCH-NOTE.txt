ClaudeMini 0.7.4-1 (beta)

Chat:
- A reply no longer stops half way: if the connection drops, the stream closes quietly, or the model reaches its length limit,
  the app keeps the text already received and asks the model to continue (Claude and Gemini).
- Longer waiting time before a quiet connection counts as dead; the screen does not auto-lock while a reply is written.
- If iOS restarts the chat page during a reply, the text received so far is drawn again.

Mic:
- Tap the mic, speak, the words appear in the input box, then press send. Tap the mic again to stop.
- Voice choice, the Live screen and read-aloud were removed.

[Chat hang fix]
- GeminiStream/ClaudeStream: watchdog timer (live streams only). No first byte within 45-150 s (Gemini, by model) or 30-45 s (Claude), or silence mid-stream for 60-150 s: the task is cut and, if no text arrived, restarted silently on a fresh connection (max 2 times); otherwise finishes with a Network error so the existing continuation logic keeps the partial reply. Late callbacks of replaced sessions are ignored.
- Idle timeouts shortened (live 100/160 s, single request 180/360 s).

[Release]
- Official 0.7.4 (beta 0.7.4-1 promoted).

[Beta update row]
- Settings > Data has a "Bản cập nhật beta" row again: password prompt, then the usual update pop-up (no separate page). The Software Update page keeps only the automatic-check option and always uses the normal releases.
- Only one password opens the developer channel (new PBKDF2 verifiers; the password itself is not in the repo). The repository secret DEV_UPDATE_PASSWORD must hold the same password so developer builds are encrypted with it.

[No lock-out]
- Developer gate: wrong passwords are no longer counted and nothing locks the update section. Old wrong-try counters / one-hour locks stored by earlier builds are wiped on every attempt, so the right password is never refused.

[Material 3 / accent / gradient / fonts]
- Material.h/.m: tonal row cards (large outer corners, small inner ones), section headers (collapsible in Settings), Material switch, gradient slider with a ring thumb, cookie-shaped mascot, moving gradient view.
- Appearance > Design style: Classic or Material 3 (Settings rows become cards with circle icons, left-aligned title, folding sections; chat bubbles get rounder shapes).
- Appearance > Accent colour: new fixed (non-scrolling) page like the reference video: tinted gradient page, preview card with hex and mascot, Hue / Saturation / Brightness sliders, ten ready colours, Default button. The picked colour tints the whole palette (backgrounds, cards, borders, chat). Picking a skin drops the custom colour. Skins moved to Appearance > Chat theme.
- Chat theme: new wallpaper "Gradient động" (moving gradient built from the accent colour, light or dark).
- Font page: SF Rounded added (rounded design of the system font, iOS 13+; iOS 12 keeps the normal system font) and a 7-step weight slider. All [UIFont systemFontOfSize:...] go through FontStyle.m (method exchange), the chat web view gets the same font stack and weight.
- Not compiled or run on a device.

[0.8.0 beta 13]
- One set of Material 3 motion tokens in Material.h/.m: duration tokens (50..500 ms), easing curves (emphasized decelerate 0.05/0.7/0.1/1, emphasized accelerate 0.3/0/0.8/0.15, standard 0.2/0/0/1) and the Expressive springs (spatial fast 0.6/800, default 0.8/380, slow 0.8/200; effects 1.0/3800, 1.0/1600, 1.0/800), converted to CASpringAnimation (damping = 2 * zeta * sqrt(k)) and UIView springs whose duration is the settling time. Sources: material-components-android Motion.md, Compose MotionScheme and the open-source ports; the two sources disagree on some transition lengths, the choice is 400 ms enter / 200 ms exit.
- Every existing Material animation now uses these tokens (card press, button press, switch, slider, thumb, section fold/unfold, row entrance).
- New: dialogs (confirm, update, model, choice) grow from 0.9 on the spatial spring, fade in on the effects spring and shrink + fade out in 150 ms; the tool menu grows from 0.85; the history drawer opens with emphasized decelerate (400 ms) and closes with emphasized accelerate (250 ms); layout changes and the first chat reveal use the same tokens.
- New: screen changes use the Material 3 shared-axis transition (30 pt slide + fade; 400 ms in, 200 ms out). An edge swipe back keeps UIKit's own interactive pop.
- New: rows without a card (chat list, model list) dip on the spring when pressed; buttons that cover a big area no longer shrink when pressed; the choice-popup rows no longer flash the accent colour in Material 3.
- Reduce Motion switches every one of these animations off.
- Not compiled or run on a device.

[0.8.0 beta 14]
- Press on a card (list row), rewritten after the video:
  * the corner morph is no longer a Core Animation path interpolation (it could bend the outline while the spring overshot, and the ripple mask jumped to the final outline at once, so the ripple stuck out of the corners). The corner radii are now numbers solved frame by frame with the exact spring formula (Expressive spatial fast: damping 0.6, stiffness 800), clamped to 0...half height, and the card shape and the ripple mask get the very same path every frame.
  * the ripple (10 % of the text colour, as in Material 3) grows to the farthest corner in 450 ms with the emphasized decelerate curve and STAYS while the finger is down (before it faded half-way and left a hard edge); it fades in 300 ms when the finger leaves.
  * the dip (scale 0.975) is kept, on the same spring.
- Not compiled or run on a device.
